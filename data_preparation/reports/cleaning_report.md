# Cleaning Report

_Generated by `scripts/clean_dataset.py`. Input: `data/raw/raw_pump_dataset.csv` (unchanged, checksum-verified). Output: `data/interim/cleaned_pump_dataset.csv`. Every changed cell is listed in `data/interim/cleaning_cell_changes.csv`._

## Summary
- Raw rows: **7,354** → cleaned rows: **7,210** (removed 144 redundant duplicates; no other rows deleted)
- Cells changed: **6,375**
- Columns: 29 source columns kept with original names and engineering units; added `Symptom_Keys`, `Label_Missing_In_Source` and audit columns (`Imputed_Columns`, `Converted_Columns`, `Invalid_Columns`, `Suspect_Outlier_Columns`, `Merged_Record_IDs`, `DQ_Flags`, `Raw_Row`).

## Guiding principles
1. **Never edit the raw file**; all changes are code, re-runnable and logged cell by cell.
2. **Don't delete information**: only provably redundant rows are dropped; implausible values become NaN with the original preserved in the audit trail.
3. **Don't fabricate diagnoses**: missing fault labels, causes, severities and priorities become `Unknown`, never the mode.
4. **Extreme ≠ wrong**: statistical outliers are kept unless they contradict their own record.
5. **Flag every imputation**, so imputed values can be excluded when deriving evidence.
