# Domain Source Notes

The project knowledge model was informed by general centrifugal-pump maintenance literature. The following sources support the broad relationships used in the prototype:

1. KSB, **Maintenance – Centrifugal Pump Lexicon**: routine checks include smooth running, motor power input, lubrication, shaft seals, alignment, flexible coupling elements, cavitation/erosion inspection, clearances, and test runs.
   https://www.ksb.com/en-global/centrifugal-pump-lexicon/article/maintenance-1116120

2. KSB, **Dry running**: insufficient liquid can lead to overheating, abrasion, seizure and vibration; dry-running protection may be required.
   https://www.ksb.com/en-global/centrifugal-pump-lexicon/article/dry-running-1116984

3. KSB, **Operating behaviour**: operation in unfavorable low-flow ranges can cause vibration, cavitation, temperature rise and equipment damage.
   https://www.ksb.com/en-global/centrifugal-pump-lexicon/article/operating-behaviour-1118222

4. KSB, **Pipeline pump**: commonly monitored variables include inlet pressure, bearing temperature, seal pressure/leakage, fluid temperature and vibration amplitude.
   https://www.ksb.com/en-global/centrifugal-pump-lexicon/article/pipeline-pump-1116452

The numerical thresholds inside the code are academic prototype defaults, not values quoted from these sources and not OEM alarm limits.
